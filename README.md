# 分支说明

main 为高通专用，无法编译其他平台，带满血NSS驱动。

owrt 为多平台通用，MTK、QCA、QCB带有满血PPE驱动，仅支持有线，不支持无线。

# 多 WAN 负载均衡

两条及以上 WAN 按流加权负载均衡（当前为 balance 模式），每条 WAN 独立 einat NAT。
实验台验收：1:1 实测 45/55，2:1 实测 1.91:1，双 WAN 上传 5.5 Gbit/s（单 WAN 4.4）。
配置入口：网络 → 多 WAN。使用说明、验收数据与风险边界见
[docs/multi-wan.md](docs/multi-wan.md)。
